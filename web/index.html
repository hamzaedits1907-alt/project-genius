What works today

Everything here exists in the current release. Where something is limited, it says so.

Chat

Multi-turn conversations with saved history, search, Markdown, code, tables and mathematics. The assistant introduces itself as Genius and only talks about its underlying model when you ask — from measured facts.

Research with real sources

Genius searches, opens the pages and writes a report where every claim cites a page it actually fetched. A validator flags uncited claims; the Sources list comes from the fetch log, never from the model.

Images and files

Screenshots go to a vision-capable model as real pixels. Text, Markdown, CSV, JSON, code, PDF (text layer), Word and Excel files are read; scanned PDFs are not pretended to be readable.

Exact numbers

Arithmetic and table statistics are computed by tools, not guessed by the model.

Agent Mode

Describe a goal; Genius plans steps, runs them with real tools, shows each tool call, and ends with a report that separates completed from verified. On the desktop, agents work in an isolated copy of your project and ask before changes land.

Project Brain (desktop)

A map of your code: entry points, symbols, imports, who calls what, what a change may affect and which tests to run. A pattern scan, not a compiler.

Code (desktop and web)

Desktop: real projects, builds, previews, Git. Web: a code assistant that writes files you can copy, download and preview — it cannot run or test them.

Your key, your bill

OpenAI, Anthropic, Google Gemini, NVIDIA NIM and OpenAI-compatible endpoints. Genius sells capabilities, never model tokens.

Genius on your phone

The same account, the same conversations, and (if you create the key vault in Settings → Account) the same AI keys, encrypted on your device. Sign in once and everything is there.

Download for Android (APK) Open Genius Web in your phone's browser

  • Android: download the APK, open it and allow "install unknown apps" for your browser or file manager. Until the author signs releases with a permanent key the APK is named -debug; to update, uninstall the old one first.
  • iPhone: there is no App Store app yet (it needs an Apple developer account). Open Genius Web in Safari and use Share → Add to Home Screen for an app-like icon.

  • Requirements: Windows 10 or 11 (64-bit) with WebView2 (preinstalled). For the Code workspace you also need Node.js 20+ and, optionally, Git.
  • Setup: run the installer. Windows may show a warning because the installer is not code-signed yet: install only from the download buttons on this page and compare the published SHA-256 checksum.

Get a free NVIDIA API key (about 3 minutes)

Genius is built to work with NVIDIA's hosted models, and NVIDIA lets developers try them for free. You create the key yourself; it stays on your computer or in your browser tab and is never sent to Genius servers in readable form (the optional key vault keeps an encrypted copy that only your passphrase opens).

  1. Open build.nvidia.com and press Login (top right). Create a free NVIDIA account with your email, or sign in if you already have one, and confirm the verification email. NVIDIA may also ask you to verify a phone number.
  2. Open the API keys page: click your profile picture (top right) → Settings → API Keys, or go straight to build.nvidia.com/settings/api-keys.
  3. Press Generate API Key, give it a name (for example “Genius”) and an expiry, then confirm.
  4. Copy the key now. It starts with nvapi- and NVIDIA may not show the full text again. If you lose it, simply generate a new one.
  5. Paste it into Genius: in the desktop app open Settings → AI provider, choose NVIDIA, paste the key, keep the model on Auto and press Test connection. In Genius Web the same screen is under Settings; turn on “Remember this key on this device” so you only paste it once.
  • Cost: NVIDIA offers free access for development and testing, with rate limits per model. Limits and credits are decided by NVIDIA and can change — check your account page on build.nvidia.com for the current numbers.
  • “API access restricted by your organization”? Some personal NVIDIA accounts are blocked from creating keys. Try again after a day, make sure your email is verified, or ask in the Genius Discord.
  • Never share the key. Anyone with it can use your quota. If it leaks, delete it on the same API Keys page and create a new one.
  • In the browser: NVIDIA does not allow calls straight from web pages, so Genius Web uses a small relay that forwards your request and stores nothing. You are asked for permission once. The desktop app calls NVIDIA directly.

Privacy, security and known limits

What we keep

  • Web: your conversations, sources and attachments live in your account, readable only by you (database row-level security).
  • Your provider key: never saved in readable form. Only if you create the key vault is an encrypted copy (only your passphrase opens it) saved to your account so your other devices have it.
  • Desktop: everything stays on your computer.

What to know

  • Models can be wrong; research reports flag claims without a source, but check anything important.
  • Web pages are treated as untrusted data; private and local addresses are blocked.
  • Genius Pro will sell Genius capabilities (Agent Mode, custom agents, bigger task budgets), not model usage. No live billing exists yet.

FAQ and troubleshooting

Where do I get a free key?

See Get a free NVIDIA API key above.

Do I need to pay for Genius?

The desktop app and Genius Web are free to use today. You pay your AI provider for the models you use. A Pro plan for Genius capabilities is planned; no billing is live.

“The provider rejected the key”

Check that the key belongs to the provider selected in Settings, has no extra spaces, and has access to the chosen model. Press Test connection for a step-by-step report.

NVIDIA does not work in the browser

NVIDIA blocks calls from web pages. In Settings → AI provider allow the relay for NVIDIA, or use the desktop app, which calls NVIDIA directly.

Genius Web asks for my key again

Turn on “Remember this key on this device” when you save it (Settings → AI provider). Without it the key lives only in the open tab. The key is never uploaded or synced to other devices. The desktop app keeps it in the Windows credential store.

Windows says the installer is unsafe

The installer is not code-signed yet. Download only from the buttons on this page and compare the published SHA-256 checksum.

A scanned PDF cannot be read

Genius reads PDF text layers. For scans, attach the pages as images to a vision-capable model.

Agent Mode in the browser did not change my files

Correct: a browser cannot touch your computer. Use Genius Desktop for missions that edit a project.
